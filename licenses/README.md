# Licence texts

The full text of every licence that applies to something Just Player Pro ships.
`THIRD-PARTY-NOTICES.md` in the repository root says which component is under
which; this folder carries the licences themselves, because naming a licence is
not the same as providing it. The MIT and ISC licences require their permission
notice to travel with every copy, and Apache-2.0 section 4(a) requires a copy of
the licence to reach every recipient.

Just Player Pro's own licence is `LICENSE` in the repository root (GPL-3.0).

| File | Covers |
|---|---|
| `Apache-2.0.txt` | AndroidX Media3 / ExoPlayer, AndroidX, Material Components, OkHttp, ZXing, chardet4j, TapTargetView, and the vendored `android-file-chooser/` |
| `Apache-2.0-with-LLVM-exception-libcxx.txt` | `libc++_shared` (LLVM libc++), shipped as a native library |
| `MIT-DoubleTapPlayerView.txt` | The vendored `doubletapplayerview/` — Copyright (c) 2019 Viktor Krez |
| `MIT-libmpv-android.txt` | The `dev.jdtech.mpv:libmpv` wrapper — Copyright (c) 2016 Ilya Zhuravlev, Copyright (c) 2016 sfan5 |
| `ISC-libass.txt` | libass, shipped as a native library |
| `LGPL-2.1.txt` | mpv, FFmpeg and libplacebo, shipped as native libraries |
| `GPL-2.0.txt` | The GPL-2.0-or-later parts of mpv and FFmpeg, where a build enables them |

The upstream project this one began from, [Just Player](https://github.com/moneytoo/Player)
by Marcel Dopita, is released under the Unlicense and places no conditions on
redistribution.

Each text is the unmodified canonical copy, taken from the project that owns it:
the Apache licence from apache.org, the GPL and LGPL from the mpv repository,
and the MIT and ISC texts from DoubleTapPlayerView, libmpv-android and libass
respectively.
